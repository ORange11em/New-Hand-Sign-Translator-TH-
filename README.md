# HandVox — แอปช่วยแปลภาษามือไทยในชีวิตประจำวัน

HandVox เป็นแอป Windows สำหรับจัดการคำศัพท์ สร้างประโยค อ่านเสียง และตรวจจับท่าภาษามือจากการเคลื่อนไหวช่วงบนของร่างกาย คำศัพท์เพิ่มต่อได้ทีละคำโดยไม่แบ่งเป็นคำหลักหรือคำรอง

หากต้องการทำความเข้าใจซอร์สโค้ด ให้เริ่มจาก [`CODE_GUIDE.md`](CODE_GUIDE.md) ซึ่งสรุปเส้นทางการทำงานและหน้าที่ของทุกไฟล์ Python

## เปิดแอป

ดับเบิลคลิก `HandVox.bat` แอปจะเปิดหน้า GUI หลัก หากยังไม่ได้ติดตั้งสภาพแวดล้อม โปรแกรมจะเรียก `setup.bat` ก่อน

หน้าในแอปประกอบด้วย:

- **ภาพรวม** — เริ่มกล้อง ดูจำนวนคำ/คลิป และกางรายละเอียดระบบเมื่อจำเป็น
- **สร้างประโยค** — กดเลือกคำ พิมพ์คำเพิ่ม คัดลอก อ่านเสียง และดูประวัติ
- **คำศัพท์** — ดูท่าที่โมเดลรู้จัก และแก้แผนคำศัพท์ในอนาคตแยกกัน
- **เตรียมเทรน** — Wizard 5 ขั้นพร้อมสีสถานะ งานถัดไป เก็บข้อมูล ตรวจคลิป preflight เทรน และดูผล
- **ตั้งค่า** — ตั้งกล้อง confidence จำนวนเฟรมยืนยัน TTS และประวัติ
- **วิธีใช้** — อธิบายขอบเขตและลำดับพัฒนาภายในแอป

> แอปจะไม่เปิดกล้องเอง ปุ่มเริ่มตรวจจับจะถามยืนยันก่อนทุกครั้ง

## สิ่งที่ทำได้โดยไม่ใช้กล้องหรือเทรนโมเดล

1. ทดลองสร้างประโยคจากคลังคำ
2. ทดลองระบบอ่านข้อความและบันทึกประวัติ
3. จัดลำดับคำศัพท์ที่ต้องการเพิ่มในอนาคต
4. ปรับและบันทึกค่าของตัวตรวจจับ
5. ตรวจความพร้อมของไฟล์โปรเจกต์แบบอ่านอย่างเดียว
6. เตรียม schema และโครง Dataset V2
7. ตรวจรายการที่ยังขาดก่อนเทรน โดยไม่เริ่มเทรนจริง

การเพิ่มคำใน `planned_gestures.json` เป็นเพียงการวางแผน ไม่แก้ `custom_gestures.json` และไม่ทำให้โมเดลรู้จักท่านั้นทันที

## เริ่มตรวจจับเมื่อพร้อมใช้กล้อง

กด **เริ่มตรวจจับภาษามือ** จากหน้าภาพรวม แล้วยืนยันการเปิดกล้อง ตัวตรวจจับจะใช้ค่าจากหน้า **ตั้งค่า**

เมื่อโมเดลยืนยันคำแล้ว ให้ค้างท่าจนครบเวลาที่แถบแสดง ระบบจะเพิ่มคำนั้นลงในประโยคอัตโนมัติเพียงหนึ่งครั้ง จากนั้นต้องปล่อยมือหรือเปลี่ยนท่าก่อนเพิ่มคำถัดไป ด้านล่างของหน้ากล้องมีปุ่ม **เพิ่มคำ**, **ลบคำล่าสุด**, **อ่านประโยค**, **บันทึก** และ **ล้าง** โดยแสดงคีย์ลัดบนแต่ละปุ่มไว้ด้วย การอ่านหรือบันทึกจะเก็บประโยคไว้ในประวัติซึ่งเปิดดูได้จากหน้า **สร้างประโยค**

| ปุ่ม | การทำงาน |
| --- | --- |
| `Space` | เพิ่มคำที่ยืนยันแล้วลงในประโยค |
| `Backspace` | ลบคำล่าสุด |
| `Enter` | ล้างประโยค |
| `S` | อ่านประโยคและบันทึกประวัติตามการตั้งค่า |
| `B` | บันทึกประโยคลงประวัติโดยไม่อ่านเสียง |
| `Esc` | ปิดหน้าต่างตรวจจับ |

ค่าเริ่มต้นยอมรับผลที่ confidence 72% ต้องได้คำเดิมต่อเนื่อง 6 เฟรมและมีระยะห่างจากคำอันดับสองอย่างน้อย 0.12 หากยังไม่ผ่านจะแสดง “ไม่แน่ใจ” โมเดลที่ติดตั้งจากการทดลองจะกำหนดค่าขั้นต่ำของ confidence และระยะห่างตามที่บันทึกไว้ตอนวัดผล หลังเพิ่มคำแล้วต้องวางมือกลับสู่ `neutral` ก่อนระบบจะรับคำเดิมซ้ำ ค่า threshold, จำนวนเฟรมยืนยัน, จำนวนเฟรม neutral, การเพิ่มคำอัตโนมัติ และการอ่านคำปรับได้ในหน้า **ตั้งค่า**

## เพิ่มและเทรนทีละคำ

หน้า **เตรียมเทรน** รองรับการเลือกคำใหม่ครั้งละ 1 คำ โดยระบบจะสร้างขอบเขตรอบนั้นจากคำที่โมเดลใช้งานอยู่ทั้งหมด บวกคำใหม่ที่เลือก คลาส `neutral` และ `unknown` จากนั้นเทรนโมเดล TCN ใหม่รวมทุกคลาส ไม่ได้ต่อคำใหม่เข้ากับไฟล์โมเดลเดิมโดยตรง

ข้อมูลมาตรฐานเก็บคนละ 16 คลิปต่อคลาส แบ่งเป็น 4 session รอบละ 4 คลิป และควรมี accepted อย่างน้อย 14 คลิปต่อคน ระบบมีปุ่มถ่ายเพิ่มและถ่ายใหม่โดยเก็บประวัติคลิปเดิมไว้ตรวจสอบ รายงาน Accuracy, F1 และ Confusion Matrix จะแยกตามคำเป้าหมายของแต่ละรอบ

การเทรนมาตรฐานใช้ทั้ง `person_01` และ `person_02` โดยผลัดกันกันแต่ละ session ไว้ทดสอบ รวม 4 รอบ (`known_signers_session_holdout`) ทุกคลิปถูกทดสอบครั้งเดียวในรอบที่ไม่ได้ใช้คลิปนั้นฝึก โมเดลส่งมอบฝึกจากคลิป accepted ของทั้งสองคนทั้งหมด และติดตั้งได้เมื่อผล session ที่กันไว้ผ่านเกณฑ์ คะแนนนี้บอกความแม่นกับรอบถ่ายใหม่ของผู้ใช้ที่เทรนไว้ จึงเปรียบเทียบตรง ๆ กับคะแนนข้ามคนเดิมไม่ได้

ใน **ขั้นที่ 5 → วัดผู้ใช้ใหม่** สามารถเก็บและตรวจคุณภาพคลิปของ `person_03` เป็นต้นไปลง `dataset_external_v2/` แล้ววัดกับโมเดลของการทดลองที่เลือก ผลผู้ใช้ใหม่บันทึกแยกและไม่เปลี่ยนสิทธิ์ติดตั้ง ดูขั้นตอนและคำสั่งใน `TRAINING_GUIDE.md`

หน้าผลทดลองมีปุ่มหลักเดียว: **เปิดกล้องโมเดลนี้** เมื่อเลือกโมเดลที่ใช้อยู่, **ติดตั้งโมเดล** เมื่อผลผ่าน หรือ **ติดตั้งแบบทดลอง** เมื่อผลยังไม่ผ่าน แบบทดลองยังต้องยืนยันคำเตือนและสำรองโมเดลเดิม โดยไม่เปลี่ยนคะแนนให้ผ่าน ปุ่ม **วัดผู้ใช้ใหม่** และ **เปิดรายงาน** ยังคงแยกไว้

หน้าเตรียมเทรนเหลือแถบขั้นตอนเดียว โหมดด่วนอยู่ใน **ตัวเลือกขั้นสูง: เทรนด่วน** และเปิดโฟลเดอร์ Dataset ได้จาก **ตรวจคลิป → เปิดโฟลเดอร์ข้อมูล** ไม่ต้องมีหน้าสถานะ Dataset ซ้ำ

หากต้องการลองอย่างรวดเร็ว ให้ใช้ **เตรียมเทรน → ขั้นที่ 4 → โหมดด่วน** ระบบนำข้อมูลฐานคำเดิมจาก `gesture_sequences.npz` มารวมให้เองและกันคลิปคำใหม่คนละ session ไว้ตรวจเบื้องต้น จากนั้นจึงเปิดให้ทดสอบด้วยกล้อง ผลนี้ใช้ลองคำใหม่เท่านั้น ไม่ใช้แทนผลมาตรฐานของผู้ใช้ที่เทรนไว้หรือผลวัดผู้ใช้ใหม่

## หน้ากล้องและความเร็ว

หน้ากล้องเปิดขนาด 1080×680 และปรับขนาดหน้าต่างได้ ภาพกล้องแยกจากคำที่ตรวจพบ ประโยค และปุ่มควบคุม ปุ่มเพิ่มคำเปิดเฉพาะเมื่อยืนยันคำแล้ว ส่วนปุ่มอ่าน/บันทึก/ล้างปิดเมื่อยังไม่มีประโยค คำเตือนโมเดลทดลองยังแสดงตลอดการใช้งาน

กด **D** หรือ **รายละเอียด** เพื่อดูเวลาเฉลี่ยของกล้อง, ตรวจ landmark, โมเดลพร้อมเตรียม features และการวาด UI คีย์ลัดเดิม Space / Backspace / S / B / Enter / Esc ยังใช้ได้ เมื่อปิดกล้องจะบันทึกเฉพาะสถิติเวลาใน `detector_performance_latest.json` โดยไม่บันทึกภาพหรือคำพูด

ค่า **ประมวลผล FPS** วัดลูปทั้งรอบ ไม่ใช่ความเร็วเฉพาะ GPU หรือคะแนนความแม่นยำ ส่วน **ทำนายจริง ครั้ง/วิ** นับเฉพาะเฟรมที่เรียกโมเดลแล้ว สถิติใช้หน้าต่างล่าสุดไม่เกิน 120 เฟรมและแสดงผลใหม่ทุกประมาณครึ่งวินาที

รอบปรับ UI นี้ไม่ลดขนาดภาพที่ส่งให้ MediaPipe, ไม่ลดความซับซ้อนตัวตรวจจับ, ไม่เปลี่ยนโมเดล/threshold และไม่ข้ามหรือเติมเฟรมใน sequence 30 เฟรม เมื่อมือ/ช่วงตัวหายเกินเวลา `release_seconds` เดิม จะล้าง sequence ที่ค้าง แม้ยังอยู่ช่วงเก็บเฟรมแรก เพื่อไม่ปนท่าเก่ากับท่าใหม่ ข้อมูลเดิมไม่มีเวลาจริงรายเฟรม จึงยังไม่บังคับ resample เป็น FPS ที่เดาเอง ในรายละเอียดจะแสดงช่วงเวลาจริงของ sequence ปัจจุบันเพื่อใช้ตรวจการเปลี่ยนจังหวะหลังปรับความเร็ว ต้องทดสอบกับการทำท่าสดและผู้ใช้ใหม่เพิ่มเติมก่อนอ้างว่าความแม่นยำดีขึ้น

นักพัฒนาสามารถใช้ `tools/profile_detector_replay.py --video <คลิป.mp4> --output <รายงาน.json>` เปรียบเทียบการประมวลผลคลิปเดิมโดยไม่เปิดกล้อง ไม่อ่านเสียง และไม่เขียนประวัติ ตัวเลือก `--source <run_detector.py รุ่นก่อน>` ใช้ทดสอบก่อน–หลังได้ ผลนี้ไม่รวมเวลารอไดรเวอร์กล้องและการแสดงหน้าต่างจริง ไม่ใช่คะแนนความแม่นยำของผู้ใช้ใหม่

## เครื่องมือเดิมสำหรับนักพัฒนา

เปิด `HandVox_Tools.bat` เมื่อต้องการเก็บข้อมูล เทรน เพิ่ม หรือลบท่า คำสั่งเหล่านี้ไม่อยู่ในเส้นทางใช้งานทั่วไปเพื่อป้องกันการเริ่มเก็บข้อมูลหรือเทรนโดยไม่ตั้งใจ

## ไฟล์ข้อมูลสำคัญ

| ไฟล์ | หน้าที่ |
| --- | --- |
| `settings.json` | ค่าที่บันทึกจาก GUI |
| `conversation_history.json` | ประวัติประโยคในเครื่อง |
| `custom_gestures.json` | 4 ท่าที่โมเดลปัจจุบันใช้งานได้ |
| `planned_gestures.json` | คำศัพท์ใหม่ที่ยังเป็นแผน |
| `gesture_model.pt` | โมเดล TCN ปัจจุบัน (ใช้ GPU อัตโนมัติเมื่อพร้อม) |
| `gesture_model.pkl` / `gesture_labels.pkl` | โมเดล SVC เดิมสำหรับ fallback |
| `gesture_sequences.npz` | ข้อมูล sequence สะสมที่ใช้เป็นฐานตอนเพิ่มคำถัดไป |
| `dataset_v2/schema.json` | มาตรฐาน metadata สำหรับข้อมูลรุ่นใหม่ |
| `dataset_external_v2/` | คลิปผู้ใช้ใหม่สำหรับวัดผลภายหลัง แยกจากข้อมูลเทรน |
| `training_config.json` | คำตั้งต้น แผนสมาชิก จำนวนคลิป โมเดล และเกณฑ์ผ่าน |
| `experiments/` | ผล Accuracy, F1, Confusion Matrix, CSV, JSON และกราฟของแต่ละรอบ |
| `handvox.log` | รายละเอียดข้อผิดพลาดของ GUI |

ไฟล์ตั้งค่า ประวัติ log และข้อมูลจริงใน Dataset V2 ไม่ถูกนำเข้า Git ตามค่า `.gitignore`

## ความต้องการ

- Windows 10 หรือ 11
- Python 3.10 หรือ 3.11 (แนะนำ 3.11)
- การ์ด NVIDIA รองรับ CUDA สำหรับเทรนและตรวจจับบน GPU; หากไม่มีจะ fallback เป็น CPU
- เว็บแคมเฉพาะเมื่อต้องการตรวจจับหรือเก็บข้อมูล
- อินเทอร์เน็ตสำหรับติดตั้งครั้งแรกและ gTTS; หาก gTTS ใช้ไม่ได้ ระบบจะลองเสียงออฟไลน์

## ตรวจสอบโค้ดโดยไม่เปิดกล้อง

```bat
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

ชุดทดสอบครอบคลุม state machine การตั้งค่า ประโยค ประวัติ คลังคำ และ Dataset V2 โดยไม่เปิดกล้อง ไม่เล่นเสียง และไม่เทรนโมเดล

รายละเอียดการเพิ่มคำต่อเนื่อง การเก็บข้อมูลจากสมาชิก 2 คน และนิยามค่าที่ใช้วัดผลอยู่ใน `TRAINING_GUIDE.md`
