# HandVox — เครื่องแปลภาษามือไทยจากการเคลื่อนไหว

HandVox ใช้เว็บแคมตรวจจับช่วงบนของร่างกาย มือทั้งสองข้าง และนิ้วมือ แล้วแปลท่าภาษามือเป็นข้อความไทยพร้อมเสียงพูด ระบบเรียนรู้จาก **คลิปสั้นของการเคลื่อนไหว** จึงรองรับท่าที่มีการขยับแขน มือ หรือนิ้วได้ดีกว่าการดูภาพนิ่งเพียงเฟรมเดียว

## ความสามารถ

- ตรวจจับศีรษะ ไหล่ ศอก ข้อมือ สะโพก มือซ้าย มือขวา และนิ้วมือ
- บันทึกท่าละ 30 คลิปสั้น โดยคลิปละ 30 เฟรม (ประมาณ 1 วินาที)
- เรียนรู้ลำดับการเคลื่อนไหวของท่า ไม่ใช่เพียงรูปมือค้าง
- เพิ่มหรือลบท่าได้จากเมนู โดยไม่ต้องแก้โค้ด
- แสดงชื่อท่าพร้อมความมั่นใจ สะสมคำเป็นประโยค และอ่านออกเสียงภาษาไทย
- สำรองข้อมูลก่อนรีเซ็ตหรือลบท่า

## ความต้องการ

- Windows 10 หรือ 11
- Python 3.10 หรือ 3.11 (แนะนำ 3.11)
- เว็บแคม
- อินเทอร์เน็ตสำหรับติดตั้งครั้งแรก และสำหรับเสียงพูด gTTS

> ไม่รองรับ Python 3.12 ขึ้นไป เนื่องจาก MediaPipe ที่ใช้ในโปรเจ็กต์นี้

## เริ่มต้นใช้งาน

1. ดับเบิลคลิก `HandVox.bat`
2. หากเป็นครั้งแรก ให้รอระบบติดตั้งส่วนประกอบให้เสร็จ
3. เลือกเมนู `5` เพื่อเพิ่มท่าแรก
4. เก็บข้อมูลให้ครบ 30 คลิป
5. เพิ่มท่าที่สอง แล้วเก็บให้ครบ 30 คลิปเช่นกัน
6. ระบบจะฝึกโมเดลให้อัตโนมัติเมื่อมีอย่างน้อย 2 ท่า
7. เลือกเมนู `1` หรือเปิด `Run_Detector.bat` เพื่อทดลองใช้งาน

โมเดลจำแนกท่าต้องมีอย่างน้อย 2 ท่า หากมีเพียงท่าเดียว โปรแกรมจะเก็บข้อมูลไว้ก่อน แต่ยังไม่สามารถฝึกหรือทำนายได้

## การจัดกล้องและการเก็บคลิป

- จัดกล้องให้เห็นตั้งแต่ศีรษะถึงสะโพก
- ให้เห็นมืออย่างน้อยหนึ่งข้างตลอดคลิป และควรมีแสงเพียงพอ
- สำหรับท่าเคลื่อนไหว ให้เริ่มและจบท่าในลักษณะเดียวกันทุกคลิป
- เก็บแต่ละคลิปด้วยความเร็วและระยะห่างที่หลากหลายเล็กน้อย เพื่อให้ใช้งานจริงได้ดีขึ้น
- คลิกปุ่ม **บันทึกคลิป (นับ 3 วิ)** หรือกด `Space` เพียงครั้งเดียว ระบบจะนับถอยหลัง 3 วินาทีและบันทึกคลิปต่อเนื่องอัตโนมัติจนครบ; กด `Q` เพื่อหยุด

## เมนูหลัก

| เมนู | การทำงาน |
| --- | --- |
| `1` | เริ่มตรวจจับและแปลท่าจากคลิปการเคลื่อนไหวล่าสุด |
| `2` | ฝึกโมเดลจากคลิปที่บันทึกไว้ |
| `3` | เก็บคลิปให้กับทุกท่าที่ยังมีไม่ครบ 30 คลิป |
| `4` | ติดตั้งหรือซ่อมแซมแพ็กเกจ |
| `5` | เพิ่มท่าใหม่ เก็บคลิป และฝึกโมเดลอัตโนมัติ |
| `6` | ลบท่าที่เพิ่มเอง พร้อมสำรองข้อมูลก่อนลบ |
| `0` | ออกจากโปรแกรม |

## เพิ่มท่าใหม่ทีละท่า

1. เปิด `Add_New_Gesture.bat` หรือเลือกเมนู `5`
2. ใส่ชื่อท่า เช่น `สวัสดี`
3. ใส่คำอธิบายวิธีทำท่า
4. คลิกปุ่มบันทึกหรือกด `Space` ครั้งเดียว แล้วระบบจะบันทึก 30 คลิปต่อเนื่อง โดยนับถอยหลัง 3 วินาทีก่อนแต่ละคลิป
5. เพิ่มท่าอื่นด้วยขั้นตอนเดิม

ชื่อและคำอธิบายจะถูกเก็บใน `custom_gestures.json` อัตโนมัติ หากหยุดระหว่างเก็บข้อมูล ให้เปิดเมนูเพิ่มท่าอีกครั้งและใส่ชื่อเดิม ระบบจะเก็บต่อจากจำนวนคลิปเดิม

## ลบท่า

1. เปิด `Remove_Gesture.bat` หรือเลือกเมนู `6`
2. เลือกหมายเลขท่าที่ต้องการลบ
3. พิมพ์ชื่อท่าซ้ำเพื่อยืนยัน

ระบบจะสำรองรายการท่าและคลิปทั้งหมดก่อนลบไว้ใน `gesture_backups` แล้วฝึกโมเดลใหม่ให้อัตโนมัติหากยังเหลืออย่างน้อย 2 ท่า

## ปุ่มลัดขณะตรวจจับ

| ปุ่ม | การทำงาน |
| --- | --- |
| `Space` | เพิ่มคำที่ตรวจพบท้ายสุดลงในประโยค |
| `Backspace` | ลบคำสุดท้าย |
| `Enter` | ล้างประโยค |
| `S` | อ่านประโยคด้วยเสียงพูด |
| `Esc` | ปิดหน้าต่างตรวจจับ |

## ไฟล์ข้อมูลสำคัญ

| ไฟล์ | หน้าที่ |
| --- | --- |
| `gesture_sequences.npz` | คลิปการเคลื่อนไหวที่ใช้ฝึกโมเดล |
| `custom_gestures.json` | ชื่อ คำอธิบาย และสีของท่าที่เพิ่ม |
| `gesture_model.pkl` | โมเดลที่ผ่านการฝึกแล้ว |
| `gesture_labels.pkl` | รายชื่อท่าที่โมเดลรู้จัก |
| `gesture_backups` | ข้อมูลสำรองก่อนลบ รีเซ็ต หรือย้ายจากระบบภาพนิ่งเดิม |

ข้อมูลเก่าแบบภาพนิ่ง (`gesture_data.csv`) ใช้ร่วมกับระบบคลิปไม่ได้ ระบบจะย้ายข้อมูลนั้นไปที่ `gesture_backups` อัตโนมัติเมื่อเริ่มเก็บคลิปครั้งแรก

## แก้ปัญหาเบื้องต้น

- **แจ้งว่าไม่พบโมเดล:** เพิ่มอย่างน้อย 2 ท่าและเก็บให้ครบ 30 คลิปต่อท่า แล้วเลือกเมนู `2`
- **คลิปเก็บไม่เพิ่ม:** ตรวจว่ากล้องเห็นช่วงบนและมืออย่างน้อยหนึ่งข้าง
- **เปิดกล้องไม่ได้:** ปิดแอปอื่นที่ใช้กล้อง และอนุญาตสิทธิ์กล้องให้ Python ใน Windows
- **เสียงไม่ออก:** ตรวจสอบลำโพงและอินเทอร์เน็ต; gTTS ต้องใช้อินเทอร์เน็ตขณะสร้างเสียง
- **ผลทำนายไม่แม่น:** เก็บคลิปเพิ่ม โดยให้มีแสง มุมกล้อง ระยะ และความเร็วการทำท่าหลากหลายขึ้น
