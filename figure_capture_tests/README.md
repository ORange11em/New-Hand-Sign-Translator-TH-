# ชุดทดสอบสำหรับเก็บภาพประกอบรายงาน HandVox

โฟลเดอร์นี้แยกเครื่องมือทดสอบตามหมายเลขภาพในรายงาน ทุกชุดเขียนผลเฉพาะใน
โฟลเดอร์ `output` ของตัวเอง และไม่แก้ไข Dataset หรือโมเดลจริง

## ภาพและโฟลเดอร์

| ภาพ | โฟลเดอร์ | วิธีทำงาน |
| --- | --- | --- |
| 2.1 จุดสำคัญ MediaPipe | `figure_2_1_landmarks` | เปิดกล้อง กด `S` เพื่อบันทึก |
| 2.2 ลำดับ 30 เฟรม | `figure_2_2_sequence` | เปิดกล้อง กด `Space` แล้วทำท่าหนึ่งครั้ง |
| 3.1 สถาปัตยกรรม | `figure_3_1_architecture` | ส่งออกภาพที่เตรียมไว้โดยอัตโนมัติ |
| 3.2 หน้าจอเก็บคลิป | `figure_3_2_collect_screen` | จำลองการเก็บคลิปโดยไม่เขียน Dataset |
| 4.1 Confusion Matrix | `figure_4_1_confusion_matrix` | อ่าน Dataset ปัจจุบันและสร้างภาพอัตโนมัติ |
| 4.2 หน้าจอภาพรวม | `figure_4_2_system_ui` | เปิด GUI และจับภาพอัตโนมัติ |

ดับเบิลคลิก `run.bat` ในโฟลเดอร์ภาพที่ต้องการ หรือเปิด
`เปิดเมนูทดสอบภาพ.bat` เพื่อเลือกจากเมนูรวม

## ปุ่มของงานที่ใช้กล้อง

- `S` บันทึกภาพปัจจุบัน
- `Space` เริ่มจับลำดับหรือเริ่มจำลองการบันทึก
- `R` เริ่มใหม่ในภาพที่รองรับ
- `Q` หรือ `Esc` ปิดหน้าต่าง

ภาพที่ได้จะอยู่ใน `output` ของภาพนั้น ๆ พร้อมนำไปตรวจและใส่รายงาน
