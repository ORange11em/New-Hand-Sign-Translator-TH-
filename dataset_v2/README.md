# HandVox Dataset V2

โฟลเดอร์นี้เตรียมไว้สำหรับข้อมูลรุ่นใหม่ที่แยกผู้ทำท่าและรอบการเก็บข้อมูลได้

- `schema.json` ระบุฟิลด์ metadata ของแต่ละคลิป
- `metadata.jsonl` จะถูกสร้างเมื่อเริ่มใช้ Dataset V2
- `clips/` จะเก็บไฟล์ลำดับคุณลักษณะในอนาคต
- `previews/` จะเก็บวิดีโอตัวอย่างขนาดเล็กสำหรับตรวจคุณภาพ (ถ้าเปิดใช้)

คลิปใหม่จะมีสถานะ `pending` ก่อน ผู้ตรวจต้องเปลี่ยนเป็น `accepted` จึงจะถูกนำไปเทรน ส่วน `rejected` จะยังคงอยู่เพื่อรักษาประวัติการตรวจสอบแต่ไม่ถูกนำไปใช้

Dataset V2 ยังไม่ถูกนำไปฝึกโมเดลโดยอัตโนมัติ จึงไม่กระทบโมเดล 4 ท่าปัจจุบัน
