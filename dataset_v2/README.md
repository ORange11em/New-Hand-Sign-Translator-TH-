# HandVox Dataset V2

โฟลเดอร์นี้เตรียมไว้สำหรับข้อมูลรุ่นใหม่ที่แยกผู้ทำท่าและรอบการเก็บข้อมูลได้

- `schema.json` ระบุฟิลด์ metadata ของแต่ละคลิป
- `metadata.jsonl` จะถูกสร้างเมื่อเริ่มใช้ Dataset V2
- `clips/` เก็บไฟล์ลำดับ landmark ของแต่ละคลิป
- `previews/` จะเก็บวิดีโอตัวอย่างขนาดเล็กสำหรับตรวจคุณภาพ (ถ้าเปิดใช้)

คลิปใหม่จะมีสถานะ `pending` ก่อน ผู้ตรวจต้องเปลี่ยนเป็น `accepted` จึงจะถูกนำไปเทรน ส่วน `rejected` จะยังคงอยู่เพื่อรักษาประวัติการตรวจสอบแต่ไม่ถูกนำไปใช้ โหมด `extra` ใช้ถ่ายเพิ่มหนึ่งคลิป และ `retake` เชื่อมคลิปใหม่กับคลิปเดิมผ่าน `supersedes_clip_id` โดยไม่ลบไฟล์หลักฐาน

ข้อมูลแบ่งตาม `signer_id` และ `session_id` เพื่อไม่ให้กลุ่มเดียวกันรั่วไปทั้งชุดฝึกและชุดทดสอบ การเก็บคลิปไม่เปลี่ยนโมเดลทันที ผู้ใช้ต้องตรวจคุณภาพ เทรน อ่านผล และเลือกติดตั้งโมเดลจากหน้าเตรียมเทรน
